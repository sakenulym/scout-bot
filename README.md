# Scout Monitor Bot 🛴

Telegram-бот для мониторинга отчётов скаутов: алерты при молчании и итоговый отчёт за день.

---

## Что умеет

- **Слушает группу скаутов** — фиксирует каждый отчёт (имя, район, кол-во самокатов, время)
- **Каждые 5 минут** проверяет: если скаут молчит больше 20 мин — шлёт алерт в чат менеджеров
- **В конце дня (22:00)** — итоговый отчёт по каждому скауту: часы работы + все простои

---

## Быстрый старт (Railway — рекомендую)

### 1. Создай бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Напиши `/newbot`, задай имя
3. Скопируй **токен** — понадобится ниже

### 2. Добавь бота в группы

- Добавь бота **администратором** в группу скаутов (чтобы читать сообщения)
- Добавь бота в чат менеджеров (или используй личный чат)
- Узнай ID групп: добавь [@userinfobot](https://t.me/userinfobot) в группу → `/start`

### 3. Деплой на Railway

1. Зайди на [railway.app](https://railway.app) → **New Project → Deploy from GitHub repo**
2. Загрузи папку `scout_bot` в GitHub (или используй Railway CLI)
3. В разделе **Variables** добавь:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `SCOUT_GROUP_ID` | ID группы скаутов (например `-1001234567890`) |
| `MANAGER_CHAT_ID` | ID чата менеджеров или свой chat_id |
| `REPORT_TIMEOUT_MINUTES` | `20` |
| `DAY_END_HOUR` | `22` |
| `DAY_END_MINUTE` | `0` |
| `TIMEZONE` | `Asia/Almaty` |

4. Railway сам запустит `Procfile` — всё готово!

## Локальный запуск (для теста)

```bash
cd scout_bot

# Установи зависимости
pip install -r requirements.txt

# Скопируй и заполни .env
cp .env.example .env
nano .env  # вставь реальные значения

# Запусти
python bot.py
```

## Формат отчётов скаутов

Бот распознаёт гибкий формат. Подходят все варианты:

```
Район Алматы-1, 7 самокатов
р-н Медеу 3 ск
Алматы 1 - 5 самокатов
медеу: 4
```

**Правило:** сообщение должно содержать название района И число самокатов.

## Структура файлов

```
scout_bot/
├── bot.py           # главный файл, polling + планировщик
├── config.py        # переменные окружения
├── database.py      # SQLite: сохранение и чтение отчётов
├── report_parser.py # парсинг текста сообщений
├── analytics.py     # алерты + итоговый отчёт
├── requirements.txt
├── Procfile         # для Railway
└── .env.example     # шаблон переменных
```
